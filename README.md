# Web Technologies Lab

Repository containing lab projects for Web Technologies course.

## Projects

### 🛒 [Product-Catalog](./Product-Catalog)
A React-based Online Shopping Product Catalog featuring:
- Dynamic product search by name
- Category filtering (Electronics, Clothing, Grocery)
- Price range slider filter
- Conditional rendering for stock availability ("In Stock" / "Out of Stock")
- Live product count display

#### Tech Stack
- React
- Vite
- JavaScript (ES6+)
- CSS3 (Vanilla CSS)

### 🏛️ [University-Navigation](./University-Navigation)
A React.js-based Menu Navigation System for a University Website featuring:
- Responsive navigation bar with smooth multi-level dropdown menus
- React Router DOM integration for seamless page routing
- Component-driven architecture using props and JSX
- Event handling (onMouseEnter, onMouseLeave, onClick) for interactive dropdown states
- Navigation routes for:
  - **About Us**
  - **Academics** (Undergraduate, Postgraduate, PhD)
  - **Admissions** (Eligibility, Application Process, Important Dates)
  - **Research** (Research Areas, Publications)
  - **Campus Life**
  - **Placements**
  - **Contact Us**

#### Tech Stack
- React
- React Router DOM
- Vite
- JavaScript (ES6+)
- CSS3 (Vanilla CSS)

### 📝 [URL-Based-Notes-App](./URL-Based-Notes-App)
A URL-driven Notes Manager demonstrating Node.js Core Modules featuring:
- File System (s) module CRUD operations (read, write, append, delete, list)
- URL (url) module parsing and query routing
- Built purely using Node.js built-in modules without external frameworks

#### Tech Stack
- Node.js (http, s, url, path)
- JavaScript (ES6+)

### 🛍️ [MERN-Shopping-App](./MERN-Shopping-App)
A full-stack MERN application for managing shopping lists, bills, and expenses featuring:
- Complete CRUD operations for shopping items and bills
- JWT-based authentication (Register, Login, Protected Routes)
- Real-time status toggling and quantity tracking
- Responsive React frontend with modular component architecture
- RESTful Express API backed by MongoDB/Mongoose

#### Tech Stack
- MongoDB & Mongoose
- Express.js
- React.js & React Router DOM
- Node.js
- Axios & JWT
- CSS3
